Work Sans and Fraunces variable WOFF2 subsets are self-hosted here, using the font files already generated by the project. Font names, weights, Unicode subsets and fallback metrics are preserved.

Original notices and license sources: [Work Sans](https://raw.githubusercontent.com/google/fonts/main/ofl/worksans/OFL.txt) and [Fraunces](https://raw.githubusercontent.com/google/fonts/main/ofl/fraunces/OFL.txt). The accompanying OFL files carry the copyright notices and the standard SIL Open Font License 1.1 text.
